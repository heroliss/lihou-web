# 在 Liss Community 写下第一篇文章

这里可以记录实践、分享作品，也可以随手留下一个想法。上方工具栏可以插入标题、粗体、列表、链接和图片；不熟悉 Markdown 也能开始写。

## 1. 开始写作，保存身份

点击“开始写作”即可使用访客身份。访客最多发布 **10 篇文章或项目讨论**（合并计数，评论不占篇数）；注册账号不限制篇数，仍遵循单篇长度、操作频率和站点容量规则。注册时会保留当前访客已有的文章、评论与关注。

**邮箱始终可选**，以后也可以绑定或更换，具体功能以账号页当前提示为准。访客依靠当前浏览器的 Cookie 识别；清除 Cookie 或换设备可能无法再编辑原内容，想长期使用可创建账号并保存好密码。

## 2. 用标题和列表组织文字

两段之间空一行。选中文字后点击工具栏，也可以直接输入：

```markdown
## 我的小标题

这是一段正文，**这里是重点**。

- 做了什么
- 发现了什么
- 接下来想试什么
```

分享代码时，使用工具栏的“代码块”，或在代码前后各放一行三个反引号：

````markdown
```python
print("Hello, Liss Community")
```
````

## 3. 添加链接和外链图片

点击“插入链接”或“插入图片链接”，粘贴地址后补上链接文字或图片说明，也可以直接输入下方语法。**图片使用 HTTPS 外链，不是本地文件上传**；请使用自己有权分享、允许外链的图片，并写上简短描述。

```markdown
[看看 Liss Works](https://heroliss.github.io/liss-works/)

![写作流程示意](https://liss.pythonanywhere.com/static/writing-guide.svg)
```

## 4. 预览、发布，再继续交流

点击“预览”检查排版，或打开“分屏预览”边写边看（手机上切换整页预览）；确认链接和图片正常后再发布。发布后可以在自己的文章中点击“编辑”继续修改，其他读者也可以在下方评论。

如果想讨论某个工程，从 [Liss Works 工程库](https://heroliss.github.io/liss-works/projects/) 打开作品详情，再点击“交流想法”，就会进入对应的项目交流页。
