# 文章列表预览

列表对全部作者使用相同规则：从已渲染正文提取纯文本标题和最多 112 字摘要，标题最多显示两行，摘要最多三行。正文中的代码块不会变成摘要；详情页仍完整显示保存的 Markdown HTML。

正文首张有效图片可作为列表小封面。只接受公开 HTTPS 地址或本站以 `/` 开头的路径，拒绝内联数据、危险协议、协议相对地址及明显本机 / 私有网络地址。只复制校验后的 src，不复制正文图片的事件或其他属性；Jinja 仍会转义标题和属性。浏览器加载失败时隐藏封面，文字恢复满宽。外部图片不发送文章页 referrer。

桌面使用右侧横向封面，手机将配图置于文字下方；`object-fit: contain` 保留宽幅插图完整内容。未增加库、数据库字段或发文限制。模板工具不访问数据库或网络。

验证：`python -m unittest tests.test_post_previews tests.test_markdown_rendering -v`，13 项通过。隔离临时数据库的浏览器验收覆盖实际 CSS 视口 1600 / 433 / 320，无横向溢出，摘要三行截断；本地 SVG 正常显示，404 图片回到无图布局。Chrome 当前缩放为 90%，请求的物理窗口宽度与 CSS 宽度不同，因此以实际 innerWidth 记录。完成后已关闭本次独立标签并还原尺寸；没有操作正式数据库。
