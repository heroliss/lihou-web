# 从一段文字开始

![把想法写下来，慢慢整理成篇](https://liss.pythonanywhere.com/static/community-writing.svg)

### 写作与插图

工具栏支持标题、列表、代码、链接和预览。插图可点击图片按钮，也可以写：

```markdown
![图片说明](https://example.com/image.jpg)
```

图片需使用公开可访问的 **HTTPS 链接**，目前不提供本地图片上传。

### 留住你的身份

访客可发 **10 篇**文章或项目讨论，注册账号不限制篇数；注册时会保留当前访客的内容。邮箱可选，验证后可用于找回密码。

> 访客身份依赖当前浏览器的 Cookie。想换设备继续写，建议先注册账号。
